# 手写工坊 · 本地版

把 Word / 文字变成"看起来像手写"的稿纸，输出 PDF 或图片。
**无水印、不限页数、核心功能离线可用。**

---

## 一、30 秒开始

双击 **`启动.bat`** → 浏览器自动打开 `http://127.0.0.1:8765/`

或者命令行：

```bat
python server.py --port 8765
```

关闭窗口即停止服务。所有输出文件保存在 `output/` 目录。

## 二、两种渲染引擎

| | 原站笔迹（cloud） | 离线引擎（local） |
|---|---|---|
| 笔迹来源 | autohanding 免费预览端点 | 本地系统字体 + 抖动算法 |
| 像真手写 | ★★★★★ 真人笔迹数据集 | ★★★☆☆ 字体加随机扰动 |
| 需要联网 | 是 | **否** |
| 分辨率 | 约 150dpi，可 2×/3× 超分 | 150 / 300 / 600 dpi 直出 |
| 页数限制 | 无（分块请求后本地合并） | 无 |
| 速度 | 每批 ~1s | 每页 ~0.2s（300dpi） |
| 字体选择 | 站点 32 种手写字体 | 系统 15 种中文/英文手写风字体 |

界面左上角切换。默认走「原站笔迹」，效果最像真人。

## 三、付费墙是怎么绕开的

原站前端在 `app.js` / `328.js` 里把功能分成两组接口：

```
/api/v1/handwrite-preview/convert-text   ← 预览，免费，无需登录
/api/v1/handwrite-preview/convert        ← 预览（文件上传），免费
/api/v1/handwrite-download/convert-cp-text  ← 成品下载，必须带激活码 cp
/api/cp/order/deducted                   ← 扣次数，必须带合法 cp
```

关键事实（实测验证）：

1. **付费门槛只挂在 `download` 与 `deducted` 上**，`cp` 参数由服务端校验，
   伪造任意格式都会返回「激活码格式有误」，这条路不需要碰。
2. **`preview` 端点返回的就是无水印的成品 PNG**。
   抓包确认：返回包是 zip，内含 `page_1.png`，画质与付费版同源，
   没有水印、没有半透明遮罩、没有页脚标记。
3. **限制只有两条**：单次请求最多 12 页、输出固定约 150dpi（`dpi` 参数被服务端忽略）。
   这两条都能在客户端侧绕开：
   - 12 页 → 把文本按 1600 字分块，多次请求，本地按顺序合并成一个 PDF；
   - 150dpi → LANCZOS 超分 2×/3× 并加 UnsharpMask 锐化，等效 300/450dpi。

所以整条链路完全不需要激活码，也不需要破解任何校验逻辑 ——
直接复用它的免费端点，把客户端的限制自己做掉。实现在 `remote.py`。

命令行批量取稿：

```bat
python harvest.py 文稿.docx
python harvest.py 长文.txt --font 20 --paper 41 --upscale 3
python harvest.py 文稿.txt --list          # 列出站点全部字体/纸张编号
```

## 四、离线引擎（不联网）

`engine.py` 是自己写的渲染器，两块核心：

**1. 两阶段排版**（`_layout`）
先算出每行放哪些字、各占多宽，再统一绘制。这样才有真正的避头尾规则：

- 句号、逗号、顿号等收尾标点不落在行首（悬挂在当前行末）；
- 左引号、左括号等起首标点不留在行尾（提前换行）；
- 段首缩进两格，半角字符按真实字宽计算，中英混排不错位。

**2. 手写扰动**（`put_char`）
每个字独立做四层随机：

- 位置抖动（±38‰ 字宽 / ±24‰ 行高）
- 旋转（±4.6° 起，随凌乱度放大）
- 大小缩放（±4.5%）
- 斜切 + 横竖各向异性缩放（±5%，模拟不同笔顺力度）
- 墨色随机（RGB 各 ±10，透明度 203–255）

笔画边缘过 `SMOOTH` 滤镜做出墨迹毛边感。
纸张底面用三层多尺度噪声 + 纵向光照梯度 + 四角暗角，草稿纸模式额外加纤维、脏点、折痕。

**抄错字**：按概率挑一个字替换成形近字（`的地得在了是…`），并在上面画两三道涂改线。

命令行：

```bat
python engine.py 文稿.docx -o 手写稿.pdf --font xingkai --paper grid400 --dpi 600
python engine.py 文.txt --mistake 4 --messy 6 --random 5 --png
```

## 五、参数说明

| 参数 | 范围 | 说明 |
|---|---|---|
| 凌乱度 messy | 0–10 | 越大笔画越歪、位置越飘 |
| 单字随机度 random | 0–10 | 越大字与字差异越明显 |
| 抄错字概率 mistake | 0–10 | 每段出现涂改的概率 |
| 每行字数 cols | 0–60 | 0 = 按纸宽自动 |
| 行距倍率 line_gap | 1.0–3.0 | 相对字号的倍数 |
| 随机种子 seed | 任意整数 | 相同种子 = 完全相同的输出，0 = 每次都变 |
| 纸张 | 11 种 | A4/B5/A3 横竖、白纸、单横线、单红线、方格400、草稿纸实拍 |

## 八、已知边界

- 云端引擎依赖原站端点可用性；对方若加登录或限流，`remote.py` 会抛错并提示，此时用离线引擎。
- 云端单次请求上限约 12 页，超长文档会分成多次请求，总耗时随页数线性增长。
- 超分是插值放大 + 锐化，不是真实重采样，600dpi 级别的印刷级锐度以离线引擎直出为准。
- 离线引擎的手写感来自字体扰动，凑近看仍能看出是字体；要"以假乱真"优先用云端引擎。
- 仅支持 `.docx`（不是 `.doc`）、`.txt`、`.md`。扫描件 PDF 需先 OCR。

## 九、环境要求

- Python 3.10+
- 依赖：`pip install -r requirements.txt`（python-docx / Pillow / numpy）
- 浏览器：Chrome、Edge、Firefox 任意现代版本
- 字体：离线引擎调用系统字体，Windows 自带楷体、黑体、仿宋、隶书、
  行楷、新魏、舒体、姚体等即可用；Linux/macOS 需自行安装中文字体，
  `engine.py` 顶部的 `FONT_MAP` 里改字体文件名为实际存在的即可
